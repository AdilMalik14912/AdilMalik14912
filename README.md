## ⚡ Executive Bio & Core Focus

I am a **Full-Stack Software Architect and Entrepreneur** based in New Delhi, building high-concurrency enterprise logistics networks, e-commerce platforms, and API systems. 

- 🚚 **Building [ParcelUncle](https://parceluncle.com)** & **Lekya Logistics** — Enterprise-grade Hyperlocal & Pan-India Logistics Management Engine (Django 5.2, Next.js 14, DRF, Redis, Celery, PostgreSQL).
- 📦 **Building Courier Uncle** — Multi-carrier courier aggregation & routing system with dynamic distance/weight slab pricing.
- 👓 **Building [lekya.in](https://lekya.in)** — Premium online eyewear e-commerce experience with AI-assisted sizing and lens customization.
- 🚀 **Specializing in**: Multi-tenant architectures, real-time GPS tracking, automated rider dispatch, OTP verification, B2B credit invoicing, and high-throughput REST APIs.
- 💬 **Ask me about**: Python, Django, DRF, Next.js, Node.js, PostgreSQL, Redis, Celery, Systems Architecture, and Payment Gateways.
